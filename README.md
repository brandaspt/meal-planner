# Meal planner

Weekly family menu, prep plan and shopping lists, generated by two Claude Code cloud routines and published with GitHub Pages.

- `preferences.md`: household rules. Edit to change future plans.
- `favourites.md`: loved / skipped dishes. Edit from the GitHub mobile app.
- `prompts/`: what each routine does, plus the JSON format.
- `data/`: generated weeks and Coop orders, rendered by `index.html`.
- `scripts/validate.mjs`: checks the data. `scripts/notify.sh`: WhatsApp ping via CallMeBot.

## Routines

| Routine | Schedule (Europe/Stockholm) | Prompt |
|---|---|---|
| Weekly menu | Fridays 07:00 | `Follow prompts/weekly.md` |
| Coop order | Sundays 09:00 (acts every 2nd week from 1 Nov 2026) | `Follow prompts/coop.md` |

## Setup

1. **Pages:** Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
2. **Claude access:** install the Claude GitHub app on this repo, so cloud routines can clone it and push to `main` (allow unrestricted branch pushes).
3. **Cloud environment:**
   - Network access: allow `api.callmebot.com`.
   - Environment variables:
     - `WA_RECIPIENTS` = `<phone>:<apikey>` (comma-separate for more people)
     - `SITE_URL` = the Pages URL
4. **Test the WhatsApp ping locally:**
   ```sh
   WA_RECIPIENTS="<phone>:<apikey>" scripts/notify.sh "Test from meal planner"
   ```
